# 🔥 Hearth Finance

> **🚧 Status: Under Development**

A personal finance manager built to solve a simple problem: knowing how much money is actually left over each month after accounting for debts, fixed bills, and future credit card installments—clearly separating **Real Cash Balance** from **Projected Monthly Results**.

## About the Project

This is a personal study project created to solve my own financial tracking needs, built using an **AI-Driven Development** workflow where I act as the software architect—defining the domain rules, design patterns, and system structure.

* **Stack:** C#, .NET 10, Blazor, Entity Framework Core, PostgreSQL, xUnit.
* **Architecture:** Clean Architecture, Domain-Driven Design (DDD), and CQRS.
* **Current Progress:** Core domain, application use cases, persistence layer, and automated tests are complete. The Blazor web interface is currently being built.
