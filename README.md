# 🔥 Hearth Finance

A personal finance manager built to answer a simple question: **how much money will I have left after my fixed bills, debts, and upcoming credit card installments?**

## About the Project

Hearth models credit cards the way they actually work—accounting for closing dates, due dates, and installments spread across future months—so you can see the real impact of a purchase before it hits your bank account. 

This is a personal study project created to solve my own financial tracking needs, built using an **AI-Driven Development** workflow where I act as the software architect—defining the domain rules, design patterns, and system structure.

- **Stack:** C#, .NET 10, Blazor, Entity Framework Core, PostgreSQL, xUnit
- **Architecture:** Clean Architecture, Domain-Driven Design (DDD), and CQRS
